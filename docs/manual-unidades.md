# Manual: cadastrar uma nova unidade

Feito pelo **Administrador geral**. Nenhuma programação de código é necessária.

1. **Unidades → + Nova unidade**.
2. Preencha nome, endereço, cidade/UF, **fuso horário** (os horários das programações seguem este fuso), contato e, se quiser, uma imagem da biblioteca.
3. **Criar unidade** → a aba **Ambientes** abre: crie os espaços (Salão, Entrada, Caixa, Área externa…). Use ↑ ↓ para ordenar, **Renomear** e **Arquivar** quando precisar.
4. Pareie as TVs da unidade (`manual-parear-tvs.md`).
5. Programe o conteúdo: **Programação → + Nova programação**, alvo **Unidade** (vale para todas as TVs dela, inclusive as que forem adicionadas depois).

## Atalho: copiar de outra unidade

Abra uma unidade existente → **Duplicar e arquivar** → *Criar nova unidade a partir desta*:
- **Copiar ambientes**: mesmos espaços.
- **Copiar programações da unidade**: as regras com alvo "unidade" (horários de almoço/noite etc.).
- **Criar cópias das playlists**: deixe desligado para compartilhar as mesmas playlists (uma edição vale para as duas unidades); ligue para que cada unidade tenha as suas.

Depois ajuste endereço, contato e fuso da nova unidade.

## Ativa, inativa e arquivada

- **Inativa**: as TVs da unidade mostram só a marca POP (ex.: reforma).
- **Arquivada**: some das listas, para de exibir e **mantém todo o histórico**. Pode ser desarquivada em *Mostrar unidades arquivadas*.
- Não existe exclusão definitiva de unidade.

## Acesso de pessoas à unidade

**Usuários → + Novo usuário** → perfil *Gerente de unidade* ou *Marketing* → marque as unidades autorizadas. Para gerentes, ligue só as liberações necessárias ("Parear, editar e revogar telas" e/ou "Trocar programação").
